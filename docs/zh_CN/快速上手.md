# 快速上手

目标环境为 Linux ARM64、Docker Engine 和支持本仓 Compose 文件的 Docker Compose。默认安装还需要 Bash、Python 3、curl、zstd 和 sha256sum。容器内为 Ubuntu 20.04 与 ROS Noetic。

## 首次部署

```bash
git clone --branch v0.1.3 https://github.com/TYI-Tech/TYI_E100_Firmware.git
cd TYI_E100_Firmware
bash ./scripts/check_host.sh
```

按实机填写 `machine.env` 的串口、雷达序列号、雷达与主机 IP、地面站地址和 MAVLink 系统 ID。用 `ip -br -4 addr` 确认雷达网卡已有配置的主机 IP。如需配置专用雷达网卡，见[设备配置](设备配置.md)。

```bash
bash ./deploy.sh
bash ./validate_stack.sh
```

默认从 GitHub Release 下载 Linux ARM64 镜像包并验证 SHA-256。离线板卡已载入该镜像时使用 `bash ./deploy.sh --local`，从源码构建时使用 `bash ./deploy.sh --build`。

验收成功会输出 `flight-core healthy`。启动超时请运行 `bash ./status.sh` 和 `bash ./logs.sh`，检查雷达数据、里程计和时钟。
